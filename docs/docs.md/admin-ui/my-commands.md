# My commands

![View: My commands](../assets/screenshots/prompts.png)
*The **My commands** view.*

Commands are personal, reusable prompt shortcuts. Each command stores a name and a prompt text. When you invoke a command in the **Chat** view, its prompt text is inserted into the message input. Commands save time for frequently used instructions, context-setting prompts, or structured queries.

Commands are personal — they are visible only to the user who created them.

The **My commands** view is accessible from the **My Commands** entry in the left sidebar. It is available to all users.

---

## Creating a command

► Proceed as follows to create a command:

1. Click on **My Commands** in the left sidebar.
   - The **My commands** view opens.
2. Click on the **+ New Command** button.
   - The creation form opens.
3. Enter a short name for the command in the **Name** text field. For example: `Summarise`.
4. Enter the prompt text in the **Prompt** text field. For example: `Summarise the following text in three bullet points:`.
5. Click on the **Save** button.

→ The new command appears in the commands list.

---

## Editing a command

► Proceed as follows to edit a command:

1. Click on **My Commands** in the left sidebar.
   - The **My commands** view opens.
2. Click on the command you want to edit.
   - The edit form opens.
3. Update the **Name** or **Prompt** fields as required.
4. Click on the **Save** button.

→ The updated command is saved immediately.

---

## Deleting a command

► Proceed as follows to delete a command:

1. Click on **My Commands** in the left sidebar.
   - The **My commands** view opens.
2. Click on the trash button in the row of the command you want to delete.
   - A confirmation dialog opens.
3. Confirm the deletion.

→ The command is permanently deleted.

---

## Using a command in Chat

► Proceed as follows to use a command in the **Chat** view:

1. Open the **Chat** view.
2. Type `/` in the message input field.
   - A list of your saved commands appears.
3. Click on the command you want to use, or continue typing the command name to filter the list and then press **Enter**.
   - The prompt text of the command is inserted into the message input field.
4. If required, edit the inserted text before sending.
5. Press **Enter** or click on the send button to submit the message.

→ The message is sent with the command's prompt text as the content.
