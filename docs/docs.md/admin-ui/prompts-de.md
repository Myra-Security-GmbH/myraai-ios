# Prompt-Beispiele

Diese Seite enthält einsatzbereite Prompts für die Chat-Seite. Laden Sie ein Dokument als Dateianhang hoch und verwenden Sie einen der folgenden Prompts, um es zu analysieren, zusammenzufassen, zu hinterfragen oder zu verbessern.

Die meisten Prompts liefern bessere Ergebnisse, wenn Sie kurzen Kontext ergänzen — zum Beispiel die Branche, die Zielgruppe oder Ihre Rolle. Ersetzen Sie Platzhalter wie `[Name der Partei]` durch die tatsächlichen Angaben.

Navigieren Sie zu **Chat** in der Seitenleiste. Unterstützte Dateiformate finden Sie unter [Chat — Dateianhänge](chat.md#file-attachments).

---

## Allgemeine Prompts

Diese Prompts funktionieren mit jedem Dokumenttyp.

```
Fasse dieses Dokument in fünf Stichpunkten zusammen.
```

```
Was sind die drei wichtigsten Informationen, die ich aus diesem Dokument mitnehmen sollte?
```

```
Liste alle Aufgaben, Fristen und Verantwortlichkeiten auf, die in diesem Dokument genannt werden.
```

```
Schreibe dieses Dokument in einfacher Sprache um, die auch jemand ohne Fachkenntnisse versteht.
```

```
Welche Fragen sollte ich nach dem Lesen dieses Dokuments stellen?
```

```
Was fehlt in diesem Dokument, das ich normalerweise erwarten würde?
```

```
Welche Annahmen liegen diesem Dokument zugrunde?
```

## Rechtliche Dokumente

Diese Prompts eignen sich für Verträge, NDAs, AGB, Rechtsgutachten und ähnliche Dokumente.

```
Fasse die wesentlichen Pflichten jeder Partei in diesem Vertrag zusammen.
```

```
Welche Risiken ergeben sich für [Name der Partei] aus diesem Vertrag?
```

```
Welche Klauseln sind ungewöhnlich einseitig oder nachteilig? Erkläre jede davon.
```

```
Fehlen in diesem Vertrag Standardklauseln, die üblicherweise enthalten sind?
```

```
Erkläre die Kündigungsbedingungen in einfacher Sprache.
```

```
Liste alle Fristen, Kündigungsfristen und zeitkritischen Pflichten in diesem Dokument auf.
```

```
Was müsste ich nachverhandeln, um diesen Vertrag ausgewogener zu gestalten?
```

```
Fasse diesen Vertrag so zusammen, als würdest du ihn jemandem ohne juristischen Hintergrund erklären.
```

```
Welche Definitionen in diesem Vertrag sind unscharf oder könnten zu Streitigkeiten führen?
```

## Marketing- und Markenkonzepte

Diese Prompts eignen sich für Kampagnenbriefings, Markenrichtlinien, Marktanalysen, kreative Konzepte und Positionierungsdokumente.

```
Definiert dieses Konzept die Zielgruppe klar? Was fehlt?
```

```
Was sind die drei stärksten und drei schwächsten Aspekte dieses Konzepts?
```

```
Wie konsistent ist die Botschaft mit den genannten Markenwerten?
```

```
Wie unterscheidet sich dieses Konzept von typischen Wettbewerbsansätzen?
```

```
Was würde dieses Konzept für die Zielgruppe überzeugender machen?
```

```
Welche KPIs sollten verwendet werden, um den Erfolg dieser Kampagne zu messen?
```

```
Welche Risiken könnten verhindern, dass diese Kampagne ihre Ziele erreicht?
```

```
Schreibe die Zusammenfassung überzeugender und prägnanter um.
```

```
Welche Annahmen über den Markt oder die Kunden liegen diesem Konzept zugrunde, und sind sie gerechtfertigt?
```

## Vertriebskonzepte und Angebote

Diese Prompts eignen sich für Verkaufspräsentationen, Pitches, Angebote und Angebotsdokumente.

```
Was ist das Wertversprechen und wie klar wird es kommuniziert?
```

```
Welche Einwände wird der Kunde wahrscheinlich haben, und wie geht dieses Angebot darauf ein?
```

```
Welche Belege, Referenzen oder Fallstudien fehlen in diesem Angebot?
```

```
Schreibe die Zusammenfassung in drei Sätzen für ein C-Level-Publikum um.
```

```
Welche Preisrisiken oder Unklarheiten gibt es in diesem Angebot?
```

```
Wie stark ist die Wettbewerbsdifferenzierung in diesem Angebot?
```

```
Liste die nächsten Schritte auf und wer für jeden verantwortlich ist.
```

```
Was würde dieses Angebot für einen kostenbewussten Einkäufer überzeugender machen?
```

```
Was ist der schwächste Teil der Argumentation in diesem Angebot, und wie könnte er gestärkt werden?
```

## Finanzdokumente

Diese Prompts eignen sich für Finanzberichte, Budgets, Prognosen, Investitionsanalysen, Board-Präsentationen und ähnliche Dokumente.

```
Fasse die wichtigsten Finanzkennzahlen in diesem Dokument zusammen und erkläre, was sie bedeuten.
```

```
Welche Zahlen oder Trends bedürfen weiterer Erklärung oder erscheinen ungewöhnlich?
```

```
Welche wesentlichen Finanzrisiken werden in diesem Dokument genannt?
```

```
Welche Annahmen liegen den Prognosen in diesem Dokument zugrunde?
```

```
Welche Fragen sollte ich dem Finanzteam zu diesem Bericht stellen?
```

```
Identifiziere Inkonsistenzen oder Lücken in diesem Finanzdokument.
```

```
Schreibe diese Finanzzusammenfassung für ein Publikum ohne Finanzfachkenntnisse um.
```

```
Welche Trends lassen sich über die berichteten Zeiträume hinweg erkennen, und womit könnten sie zusammenhängen?
```

```
Wenn diese Prognosen um 20 % von der Realität abweichen — welche Auswirkungen hätte das auf das Unternehmen?
```
