# Prompt examples

## View: Prompt examples

![View: Prompt examples](../assets/screenshots/prompts.png)
*View: Prompt examples*

This view provides ready-to-use prompts for the **Chat** view. Upload a document as a file attachment and paste one of the prompts below to analyse, summarise, critique, or improve it.

Most prompts produce better results when you add brief context — for example, the industry, the intended audience, or your role. Replace placeholders such as `[party name]` with the actual values.

Proceed as follows to use a prompt from this page:

1. Navigate to **Chat** in the sidebar.
2. Start a new conversation and select your gateway and model.
3. Attach a document using the **paperclip** icon or by dragging a file into the message area.
4. Copy a prompt from this page and paste it into the message input field.
5. Press **Enter** or click the **Send** button.

→ The model responds based on the document content.

> 💡 **Note:** See [Chat — Importing a file](chat.md#importing-a-file) for supported file formats.

## General prompts

These prompts work with any document type.

```
Summarise this document in five bullet points.
```

```
What are the three most important things I need to know from this document?
```

```
List all action items, deadlines, and responsibilities mentioned in this document.
```

```
Rewrite this document in plain language for someone without specialist knowledge.
```

```
What questions should I ask after reading this document?
```

```
What is missing from this document that I would normally expect to find?
```

```
What are the main assumptions this document relies on?
```

## Legal documents

These prompts are suited for contracts, NDAs, terms and conditions, legal opinions, and similar documents.

```
Summarise the main obligations of each party in this contract.
```

```
What are the key risks for [party name] in this contract?
```

```
Which clauses are unusually one-sided or unfavourable? Explain each one.
```

```
Are there any standard clauses missing from this contract that I would normally expect?
```

```
Explain the termination conditions in plain language.
```

```
List all deadlines, notice periods, and time-sensitive obligations in this document.
```

```
What would I need to negotiate to make this contract more balanced?
```

```
Summarise this contract as if explaining it to someone without a legal background.
```

```
Which definitions in this contract are vague or could lead to disputes?
```

## Marketing and brand concepts

These prompts are suited for campaign briefs, brand guidelines, market analyses, creative concepts, and positioning documents.

```
Does this concept clearly define the target audience? What is missing?
```

```
What are the three strongest and three weakest aspects of this concept?
```

```
How consistent is the messaging with the stated brand values?
```

```
How does this concept differentiate from typical competitor approaches?
```

```
What would make this concept more compelling to the target audience?
```

```
What KPIs should be used to measure the success of this campaign?
```

```
What risks could prevent this campaign from achieving its goals?
```

```
Rewrite the executive summary to be more persuasive and concise.
```

```
What assumptions about the market or customer does this concept rely on, and are they justified?
```

## Sales concepts and proposals

These prompts are suited for sales decks, pitches, proposals, and offer documents.

```
What is the value proposition and how clearly is it communicated?
```

```
What objections is the customer likely to raise, and how does this proposal address them?
```

```
What proof points, references, or case studies are missing from this proposal?
```

```
Rewrite the executive summary for a C-level audience in three sentences.
```

```
What pricing risks or ambiguities exist in this proposal?
```

```
How strong is the competitive differentiation in this proposal?
```

```
List the next steps and who is responsible for each.
```

```
What would make this proposal more compelling to a budget-conscious buyer?
```

```
What is the weakest part of the argument in this proposal, and how could it be strengthened?
```

## Finance documents

These prompts are suited for financial reports, budgets, forecasts, investment analyses, board presentations, and similar documents.

```
Summarise the key financial metrics in this document and what they indicate.
```

```
Which figures or trends require further explanation or appear unusual?
```

```
What are the main financial risks highlighted in this document?
```

```
What are the key assumptions underlying the projections in this document?
```

```
What questions should I raise with the finance team about this report?
```

```
Identify any inconsistencies or gaps in this financial document.
```

```
Rewrite this financial summary for a non-finance audience.
```

```
What trends can be identified across the reported periods, and what might explain them?
```

```
If these projections are wrong by 20%, what would be the impact on the business?
```
