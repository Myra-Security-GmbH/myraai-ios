# Getting Access

## Managed Service

AI Gateway by Myra Security is a managed service running on the Global Myra Security CDN. There is nothing to install or operate — Myra Security provisions and maintains your instance.

To get started, [contact Myra Security](https://www.myrasecurity.com/en/contact/). Once your instance is provisioned you will receive:

- Your admin URL (e.g. `https://<your-gateway-host>/admin`)
- Your initial tenant and credentials

From there you can log in to the admin UI and follow the [Quick Start](quick-start.md) guide to issue your first request.

---

## On-Premise Deployment

AI Gateway is also available as a separate on-premise offering for organisations with data-residency or air-gapped requirements. Licensing, hardware requirements, and deployment support are handled by Myra Security.

To learn more, [contact Myra Security](https://www.myrasecurity.com/en/contact/).
