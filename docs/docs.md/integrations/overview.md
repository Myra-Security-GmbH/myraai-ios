# Integrations

AI Gateway by Myra Security can be used as the AI backend for external tools and developer environments. The integrations listed below allow you to route requests from those tools through your gateway, applying your security policies, budgets, and routing rules to all traffic.

The following integrations are available:

| **Integration** | **Description** |
|---|---|
| [Claude Code](claude-code.md) | Use AI Gateway as the API backend for Claude Code, Anthropic's CLI coding assistant. Routes all Claude Code requests through your gateway. |
